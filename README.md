# Customer Purchase Analysis using SQL

## Project Overview

This project analyzes customer purchasing behavior using SQL, SQLite, Python, and Pandas.

The dataset contains 3900 customer transactions and includes information about:

- Customer demographics
- Product categories
- Purchase amounts
- Payment methods
- Subscription status
- Seasonal trends
- Discounts and promotions

## Technologies Used

- SQL
- SQLite
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code
